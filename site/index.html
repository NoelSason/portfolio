About me

I'm a junior at UC Berkeley double majoring in Molecular & Cell Biology, on the developmental genetics track, and Data Science, with an emphasis in computational biology.

A lot of my research is checking whether a number means what it claims. At Berkeley Lab, that's the statistics behind a study of how disease changes the microbes in the body. On my own, it was an audit of a published brain-signal benchmark that a baseline with no brain data beats. I'm also learning computational protein design in the Lewis Lab, and I'm making the images in an open-source math tutor readable to screen readers.

Outside research, I build Scope, a set of study tools I started in early 2026: a Chrome extension that searches a student's course materials, Lectra, an iPad app for reading and marking them up, and Polya, a tutor that works only from a student's own course materials. I'm the only developer on all of them.

Off the clock, I co-run the South Indian Society at Berkeley, a student organization with more than 200 members, and I'm learning to DJ house and tech house.

  2. Research Independent, October 2026 18.8% accuracy without using any EEG

    Auditing an imagined-speech EEG benchmark

    A published benchmark asks a model to tell which of 39 words a person is imagining from their brain signals. I tested whether it measures that. A baseline that never looks at the EEG, only at the previous word, scored 18.8%, above the published 13.88%. With whole recording runs held out, real labels beat shuffled labels by only 0.64 points, within noise. One participant, self-published, not peer-reviewed.

    Python, PyTorch, scikit-learn

    Paper and code on GitHub

  4. Prototype Cal Hacks 13.0, solo 500/500 records in 13.8 s

    Overclock

    A browser agent normally looks at the page, asks a model what to do, clicks, and starts over. Overclock plans the task once, compiles the plan into a program it can check, and replays it without asking the model again. On the hackathon's mock apps and its own checker, it reconciled 500 of 500 records in a median 13.8 seconds, re-reading every write to confirm it. It failed at sign-in on an app it had never seen, so it doesn't generalize yet.

    TypeScript, Playwright, SQLite, Claude

    Code on GitHub

Meet Noel Sason.

You read my name. A human cell can't, because human cells don't make pyrrolysine, the O. It's the 22nd amino acid, and only some microbes, like this one, can read UAG as pyrrolysine instead of "stop."

Now select any DNA letter to see what one change does. I built a whole app around that idea, One Base Change, for Apple's Swift Student Challenge in 2026.
